def read(X):
    s = Screen()
    s.register("a", entry=lambda v: np.asarray(v, float))
    s.place("a", np.asarray(X, float))
    return s.read()

  11. 11B1

    Register a lens that throws away all but the strongest direction of a signal, then rescales so every joule comes back. Ask the library to certify it. Does it pass?

    def drop_mode(x):   # rank-1, renormalised to the original energy
    U, S, Vt = np.linalg.svd(x, full_matrices=False)
    S2 = S.copy(); S2[1:] = 0
    B = (U * S2) @ Vt
    return B * (np.linalg.norm(x) / np.linalg.norm(B))

s.register("a", entry=drop_mode, inverse=lambda x: x)
c = s.certify("a", eeg[:, :2])
c.residual, c.K_signal, c.lossless
    answer

    residual 0.729452 — K_signal 1 — lossless: False

    The residual is under 1, so it beats the trivial inverse that returns nothing — the energy check passes. It fails on the other half: what was thrown away is structure, and the leftover resolves it. Neither check alone would have caught this; that is why the verdict is a conjunction.

    kappa0 = 0.25 * np.log(3)

    answer

    The mass gap's floor comes from counting. A stack of n cubes is fixed by its n−1 steps, each a free choice among three, and its outside has 4n+2 faces. At n = 8, how many stacks are there and how big is each one?

    answer

    2187 stacks, each with 34 faces

    The interior bound replaces a cosine with the parabola 1 − x²/2. That single step is the only thing in the whole argument a reader has to take on trust. Check it at the angles the unit uses.

    x = np.array([0.1, 0.3, 0.5, 0.7])

    answer

    The parabola sits under the cosine every time, and that direction is what makes the chain safe: replacing the cosine with something smaller can only make the bound on μ larger, and an upper bound that errs upward is still an upper bound.
