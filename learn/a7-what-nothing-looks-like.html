What Does
Nothing Look Like?

Every read in this curriculum answers the same shape of question: is there more here than there would be if there were nothing?

Which is useless until somebody says what nothing looks like. That choice is made in every unit so far, usually in one line, and it decides the answer completely.

Taught last because it needs the earlier units as examples. It could equally have been taught first.

That sentence is the whole of this unit. Everything below measures what each choice costs.

The test a null has to pass

How do you know your “nothing” is a fair one? There is one direct check:

apply the null to a draw from itself — it should find nothing

Generate data that genuinely has no structure by the null's own definition, hand it to the same instrument, and count what it reports. A correctly calibrated null finds about zero. If it finds five, then five is what it will add to every real measurement you ever make with it.

The test is cheap, it needs no ground truth, and it is the only way to catch a null that is simply set too low. On the next slide it is run on a real object: the internal transport of a small language model, the same kind of thing unit D1 read.

This check tells you the level is honest. Whether the null asks the right question is a separate matter: a perfectly calibrated null can still destroy the wrong thing.

The level has a name in the instrument: the read is noise_floor, and the count of what stands above it is basis_dim — how many directions the record genuinely spends its energy on — alongside top_share, the fraction the strongest one takes. These slides use the English words throughout; the identifiers are given here once so a reader can find the same quantities in the reference.

What shuffling every entry destroys

The tempting way to make “nothing” out of a table of numbers is to shuffle all its entries. Keep every value, destroy every position. It sounds maximally fair, and the data shows what it costs:

layerlargest entry sits atsize, against the typical entry
5(447, 138)134.2×
10(447, 138)455.6×

The same coordinate, on both layers. A few specific positions carry enormous weight, and they are the same positions from layer to layer, which makes them a property of the model.

Shuffle every entry and those few huge values get sprinkled evenly across the whole table. That manufactures a broad bulk of moderate values, and a bulk is exactly what a floor is measured from — so the floor lands low. The null fails in the direction that flatters your result.

A shuffle that destroys more than the question asked about looks rigorous, and it is the most respectable way to get a wrong answer.

Nulls that keep the shape

The fix follows from the rule. The question is whether the magnitudes line up into a pattern, so that alignment is what a null destroys. How big the entries are and where the weight sits — the object's magnitude profile — is what an honest null holds fixed.

So three nulls, each holding the profile fixed and destroying only the alignment:

nullkeepsdestroys
sign flipevery entry's size exactly — every row total, every column total, the lotthe signs
within roweach row's set of valueswhere they sit in the row
within columneach column's set of valueswhere they sit in the column

The gap between the two groups is the whole problem. Same matrix; the floors differ by more than four times, and everything above a floor is what you go on to report.

Is thirty draws enough?

Two of the five floors on that table are computed in closed form. The other three are sampled — drawn 30 times from the null and read off — and the comparison this whole unit rests on puts a sampled floor against an analytic one. Within-row does not calibrate on this transport, and the read says so. It returns its floor — the 9.669 in the table above — with the flag set. Each null encodes an assumption about what would count as nothing on this object; this one's does not hold here, and the number arrives labelled.

An unlabelled floor displaces every number downstream by the same hidden amount, and every one of them still looks fine. The label is what makes the condition visible, and it carries more than a withheld number would: the caller sees the figure the null arrived at and the flag saying the null cannot stand behind it.

The largest effect of any single choice

Every unit before this one measured things against a background of nothing. This one is about the background, and it has the largest effect of any single choice in the whole construction — on one matrix, 41 modes or 1, from nothing but the definition of nothing.

  • Every read carries a null, stated or not. If you did not choose one, something chose for you, and its default is unlikely to fit your object.
  • Keep the record's own shape; destroy the thing under test. A shuffle that destroys more manufactures the very bulk the floor is measured from.
  • Run the null against itself. Cheap, needs no ground truth, and catches the whole class of floors that are simply too low.
  • A null can be calibrated and still be the wrong question. The check tells you the level is honest, not that you asked the right thing.

Which reframes a result in unit D2. A method compared against plain similarity lost badly — because the two sides had been given different stopping rules. That was not a bad result. It was a badly chosen null, and it produced a confident, reproducible, entirely wrong number, exactly as this unit predicts.
