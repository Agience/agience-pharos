Where to Go Next

The course ends with the whole procedure run on a record it had never read. This page is the handover: what each read is called when you type it, where the code and the data live, and what keeps the work going.

Nothing here is a lesson, and no number on this page is measured. Every page that carries measured numbers regenerates them from running code each time it is built; this one carries names and addresses, which is why it can be written by hand.

What the course leaves you with is a procedure, not a result. Ask whether anything is there before believing any read of it. Ask whether there is enough record to say. Check that the null removes the thing you are looking for and not something else. Say which direction you asked in. Every one of those has a unit behind it, and the last unit runs all four in order on unfamiliar ground.

Two further things the course establishes and this page does not repeat: there are perfect relationships the instrument reports as noise, and there is a rule that says which. And the reads describe the array — what they mean about brains, markets or land belongs to whoever owns the subject matter.

The lessons teach in words. The library uses identifiers.

The course names its reads the way an optician would — the fill fraction, the étendue, the Strehl ratio, the count. The library names them the way code has to. They are the same reads under two vocabularies, and until you have the map, a lesson you understood can arrive as an interface you have never seen. The reference page measures how far apart the two vocabularies sit and prints the count; this is the map itself.

The live value of each read, on both of the course's records, is on the reference page — that page is generated, this one is not.

Typing it

The library is pure Python over numpy, Apache-2.0, and has no model in it.

pip install entroptics

Then the whole of the course's first move, in four lines:

from entroptics import Aperture ap = Aperture(W) # W: one ordered axis, one feature axis ap.optics() # the intrinsic reads, in one dict clean, info = ap.extract() # the resolved signal, in W's own units

Every read on the previous slide is an attribute on ap, so ap.strehl and ap.etendue answer directly. optics() gathers the intrinsic ones into a single dictionary. extract() returns the cleaned screen together with a dictionary carrying the count, the contrast and the coherence.

There is one number that is yours, and the library will not choose it for you. The false-alarm level — far — is what a count is taken against, and extract(far=...) takes it. Everything else the instrument uses it derives from the record in front of it. That is the whole claim, and it is the one thing to keep hold of when you point this at something of your own.

What keeps it going

This is independent work, built alone on local hardware. There is no institution behind it and no funding round under it, and what that decides is pace, not access: what is finished stays public and openly licensed, the course included, and nothing here is moving behind a paywall later.

If you cannot sponsor, the other thing is worth more. Point the instrument at a record nothing here would have thought of — seismic traces, order books, flow cytometry, turbine vibration, an archive of your own — and say what it told you, especially if what it told you was wrong. A method that has only ever been run by the person who built it has not been tested. That is the exchange on offer, and it is not a small one.

One habit to leave with

Run the null first.

Every number the last unit read off that elevation grid was large, and every one of them would have looked as convincing on a record with nothing in it. One shuffle settled which of the two it was, and it took a second.

That is the whole discipline the course was built to hand over, and it survives being carried anywhere: a read is only worth what its null is worth. The instrument will happily report a number on noise. Knowing that, and checking, is the part that is yours.
