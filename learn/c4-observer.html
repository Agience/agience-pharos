Entroptics / lesson eleven · what to forget

Observer

A system that observes has to decide what is still happening and what has merely happened. Almost every system answers this with a flag and a timeout somebody chose.

This one has neither. There is no field recording whether something is present or past, and no number anywhere saying how long things last.

tense is decay, not deletion

The dog is howling; then it is not; but it did — and that it did is still a signal, just a quieter one.

One observation, one curve

When something is observed it is not filed as a fact. It is put on the screen with an energy, and from then on its amplitude is that energy multiplied by how much of it survives the time since:

amplitude(Δt)  =  energy × C(Δt)

Δ is the Greek letter delta, meaning “the change in”, so Δt is simply how long ago. C is the survival curve — the same shape unit A3 measured as a point-spread function, now doing a job.

Read that formula again, because of what is missing. There is no is_current field. Nothing is marked as expired, and nothing is deleted on a schedule. An observation from a year ago and one from a second ago are the same kind of object, at different heights on the same curve.

Which raises the obvious question, and it is the one this unit is about: where does the curve come from? If somebody picks it, all the machinery above is just a timeout wearing a costume.

Where does “now” end?

If everything is on one curve, something has to say which part of it counts as the present. The answer is not a cutoff. It is the same question every other unit in this curriculum has asked:

how many of these are signal?

Take all the amplitudes currently on the screen, sort them, and find where they stop looking like one group and start looking like a tail — exactly the instrument units A1 and A2 used to decide how many modes stand above the floor. Everything at or above that break is “is”. Everything below is “was”.

So the present is not a duration. It is a property of the whole bag of amplitudes on the screen right now — and the bag changes as things cool, so the answer changes with it. That is the claim.

At now = 23 the present is 2 observations deep. Three ticks later, at now = 26, it is 8 deep — the present got longer as time passed. By now = 30 it has settled back to 4.

Nothing was reconfigured between those rows. What happened is that the freshest observations cooled into the flat part of the curve, so the biggest gap in the sorted amplitudes moved — and the biggest gap is the boundary. A fixed window of “the last five minutes” could not do this, and would be wrong in both directions: too short right after a burst, too long during a quiet spell.

The control: a screen that never measured

Everything above depends on the curve being real. So take the same 24 observations, give the screen no way to measure them, and ask it the same question — at now = 10,000, far beyond anything it saw.

Everything is still present. Nothing has been forgotten, ten thousand ticks later, because nothing was ever measured — and the screen reports its state as unmeasured, which is a reading a caller can act on.

A screen with no measured curve reports unmeasured and says why. A fallback to a reasonable-looking default decay would be indistinguishable from a real measurement at the point of use.

How few ticks is too few

Every curve on this slide deck was fitted from a history. A history can be short, and at some point there is not enough of it to fit anything — so where is that point? Swept downwards, same planted system, only the number of ticks changing:

At 2 ticks the screen reports unmeasured — and that is a word, not a small number. It does not fit a fast decay to two points and hand back a rate; it says the rate was never measured, and the state says the same thing. From 3 ticks on it fits.

So the boundary is three ticks, which is where it should be: two points define a line through any pair, and the third is the first one that can disagree with it.

This slide exists because the unit was carrying an unmeasured claim. It said an earlier survey had reported this boundary, that the planted system “still fitted cleanly at 8 ticks”, and that the behaviour was therefore not reproduced and not taught. Eight is nowhere near the boundary. The test was run at one value, above the edge, and read as evidence about the edge.

How you know nobody picked anything

All of this rests on a promise: that no timescale, threshold or capacity was chosen by a person. That is easy to claim and easy to violate later — one plausible constant slipped in during a fix and the whole design quietly becomes a timeout again.

So it is checked mechanically. A test reads the module's own source, walks its syntax tree, and collects every decimal number the code contains. Across 1,112 lines, the complete list is:

0.0 · 1.0

Zero and one. Nothing else. No half-lives, no fudge factors, no 0.95 that someone found worked well. Every other number in the behaviour above — the curve, the break, how much fits in memory — is measured at run time from the data or from the machine.

The test asserts that it found some decimal numbers before checking which ones, so a run that read nothing fails.

A point-spread deciding what is still happening

Unit A3 measured how a signal's influence falls away along its ordered axis and called it a point-spread function. This unit is that same curve deciding what a running system still treats as happening. It is the clearest case in the whole programme of an instrument read doing a job.

  • Tense is a height on a curve, not a flag. Present and past are one read at two bands, so nothing has to be migrated from one state to another and no update can be missed.
  • The boundary is measured, and it moves. It is the biggest gap in the current amplitudes — the same “how many are signal” question as everywhere else — so it responds to what is actually on the screen.
  • Unmeasured means unforgetting, loudly. No default curve is substituted.
  • Two decimal numbers in the whole module, enforced by a test that cannot pass vacuously.

That closes the four tiers. Signal made the numbers, the aperture read them, the substrate keeps them, and the observer decides what is still true. Every one of them was built on the same instinct: derive it, and land on zero when the record cannot answer.
