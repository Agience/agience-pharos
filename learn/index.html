49 lessons that start at grade-ten mathematics and end at a working instrument — what a read actually measures, what it costs to move a signal, and how far the method carries outside the place it was built.

Every check counted above recomputes a figure — sometimes a whole row of them — from the running code each time a page is built, by a script that ships beside it and fails if a single value has moved. The count is of checks, so it is a floor on the number of figures verified, and the true tally is higher.

Some things are not in that count, deliberately. A few claims are read from a dated record, one is carried as a pointer with a table of what it rests on and “not checked” against each row, and one figure quoted elsewhere in this system is left unmeasured because its numerator and denominator live on different machines. Each of those says so on its own slide, and carries its own evidence.
