What Is This Number Measuring?

Every read on this course returns a number. This unit is the three questions that establish what one of them measures, and all three are answered the same way: vary something that should not matter, and read again.

testwhat you varywhat it catches
onethe amount of recorda number that is reporting how much you had
twothe nulla null that leaves untouched the thing the read measures
threethe other side of a comparisona margin that came from a difference nobody matched

The course's front page names three readings that were correct, repeated on every run, and measured a different quantity from the one they were read as: a shortage of data in A5, a stopping rule in D2, a choice of null in A7. One of these three tests finds each of them.

All three run on the two records this course has carried the whole way down, and every figure on these slides was measured here. The arithmetic in each case was already right — which is why these tests exist at all.

Test one: halve the record

The EEG, read the way every unit in this course reads it — 4 columns, same instrument, same settings. The only thing that changes down this table is how many rows the read is given.

At 200 rows the read returns 0, and at 400 it returns 1. Both are correct arithmetic on the record they were given. The zero is a measurement of how much record there was.

Attenuation says the same thing along its own scale: 0.000000 at the two short lengths, then 0.277159 at 800 rows. A read that returns exact zero has found nothing to measure, and at 200 rows there was nothing it could resolve.

This is unit A10's question — how much record does a read need before its answer means anything — as a test each read answers for itself. Halve the record. If the answer changes, the answer was partly about the length.

What survives the halving

Run the same test on the ordered-axis read, on both records at once. The EEG on the left, the market's month-to-month changes on the right, each at a quarter, a half and all of its own rows:

The verdict holds at every length. The magnitude does not. The EEG's z runs from +21.034 to +46.058 across these four reads — it more than doubles — and it is far above 2 in all of them. The market's changes stay near zero in all of them.

the verdict is the answer · the magnitude is the read and the record together

So a reader who says "the EEG scores +41.287" is quoting a number that was +46.058 on half the record. A reader who says "the EEG is far above the line and the market's changes are not" is saying something that held on every one of these eight reads.

Which is what the test is for. It does not tell you a number is wrong. It tells you which part of the number to carry away, and that part is the part that survived.

Test two: check the null destroys what the read measures

A null is a version of the record with the thing you are looking for taken out, so the read has something to be compared against. Take the standard one — shuffle the rows into a random order. Every number survives; only the sequence is destroyed.

Now run two reads against that one null, on the same record, at 5 seeds:

readon the recordon a row shuffle, 5 seeds
coherence z — the ordered axis+41.2872 -1.0462 to +0.3724destroyed
Ksignal — the columns11 at every seed untouched
contrast — the columns1.3193761.319376 at every seed untouched

The same six digits at all 5 seeds, and the agreement runs far past six: the widest any shuffle departs from the record is 9e-16, which is the last bit of a double and comes from adding the same numbers in a different order. A row permutation reorders the rows and changes no column's relationship to any other, so the column covariance comes back numerically identical — checked here, and it does: identical.

So one null does two different jobs. For the ordered read it removes exactly what the read measures, which is what makes it a null. For the column read it removes nothing the read can see, so comparing against it establishes what a reader already knew.

The test in one line: apply your null and read again. The number should collapse. If it comes back unchanged, the null and the read are measuring different things, and the comparison between them is a comparison of the record with itself.

Test three: match the other side

Two records, one read, and a margin between them. The EEG is read at 4 columns because that is its natural shape; the market is read at 8 because there are 8 companies. Both choices are reasonable, and the comparison between them is not:

read at its own widthrows × columns contrast
the market's monthly changes70 × 82.2202
the EEG800 × 41.3194
the margin 0.9009

Now read the EEG at the market's width. Same bytes, same instrument, one difference removed:

read at one widthrows × columns contrast
the market's monthly changes70 × 82.2202
the EEG400 × 82.1609
the margin 0.0594

The margin falls from 0.9009 to 0.0594. Most of what looked like a difference between two records was a difference between 4 columns and 8, and unit D8 is where the same bytes at different widths are read side by side.

This is the shape of the benchmark result in unit D2, recorded in that benchmark's own notes: one side kept about 1.2 items where the other kept about 3.6, and the reported margin was the difference in how many were kept. A comparison is a claim about two things alike in every way but one. Test three is how you find out how many ways there actually were.

  • Every number on this page is correct. None of these three cases is an arithmetic error, and none would be caught by checking the arithmetic. Each is a correct measurement of a quantity a reader was not asking about.
  • The verdict is what survives. The EEG reads far above the line at 800 rows and at 200; its z is +41.287 at one and +32.907 at the other. Carry the verdict away and the magnitude stays attached to the read that produced it.
  • A null is a null for one read. A row shuffle is exactly right for the ordered axis and leaves the column reads numerically identical — the column covariance is provably unchanged, so nothing about the comparison could have gone the other way.
  • Match one thing at a time. The width was the whole margin here. Whatever else two records differ in, each difference is a candidate for what the margin measured.

Run these three on your own read before quoting it. They cost three lines each, and every one of the three findings the course's front page carries would have been caught by one of them — A5 by test one, A7 by test two, D2 by test three.

And when the read is one you have never used, unit A16 is the question to ask first: how far is its answer from what a record with nothing in it would give?
