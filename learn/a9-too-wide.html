Entroptics / lesson twenty-one · the sweep

Too Wide to
Read at Once

Every record so far has been small enough to hand over whole. Real fields run far wider: a radio capture, a wide sensor array, a spectrogram of a long recording.

The obvious response is to feed the whole thing in and wait longer. That costs more time, and on a signal occupying a small part of the width it also returns a wrong answer. This unit measures how wrong.

One faint band, 40 columns wide. The field around it grows from 2,048 to 32,768 columns and the signal is never touched.

Nothing about the signal changed between those rows. Same 40 columns, same strength, same shape. Only the amount of unrelated data around it grew.

At 32,768 columns the read is +0.445 — indistinguishable from nothing. The signal is still there, exactly as strong as it was when the same read returned +14.33. It has simply been averaged against 32,728 columns of noise.

This is the ordinary arithmetic of averaging. A read over the full width asks “is this field ordered?”, and across a field that is almost all empty the answer is no.

So do not read it all at once

Fix the aperture at a width the instrument reads comfortably — here 1,024 columns — and slide it across the field. Each position is its own small read. Nothing is ever decomposed at full width.

The gate on each patch is coherence, the read from unit A4: does this patch have any order in it at all? Patches that answer no are dropped without further work; the expensive part runs only where there is something to look at.

The band is reported as the patch that contained it, not to the column — the aperture is 1,024 wide, so that is the resolution the answer has. An answer more precise than the instrument would be an invention.

The cost of asking many times

There is a catch in sliding an aperture, and it has nothing to do with signals. A level like “call it real above z = 1.64” is chosen so that a question asked once is wrong about one time in twenty.

A sweep across 32 patches asks that question 32 times. On a field containing absolutely nothing, it should therefore be wrong about 1.6 times per field — which is what one-in-twenty means when you ask twenty-odd times.

So it was asked of pure noise, 384 times — 12 empty fields at 32 patches each, because a rate read off four fields is a number with a spread nobody printed:

One question in twenty is 0.0500. Measured over 384 of them, the single-question level fires at 0.0625 — more often than nominal, not less. The library predicts that in its own docstring: the coherence z's permutation distribution is “mildly right-skewed at small N, so the one-sided normal tail is approached”. A right-skewed null puts more weight in the upper tail than the normal curve does, so a threshold read off the normal curve is crossed more often than the number on it says.

Twelve empty fields is what it takes to read this rate. Four fields give 0.0938 per question, half again what twelve give, and 3.0 false bands per field against an expected 1.6 — a spread wide enough to move the conclusion. The number of fields is part of the measurement, and it belongs beside the rate wherever the rate is quoted.

The library raises its own level to z = 2.96 by default — derived from the patch count, not chosen — and finds 0 in 12 empty fields.

This is unit A7 again, from a new direction. There, what counted as “nothing” depended on what you destroyed. Here it depends on how many times you ask. Both change the null, and the data stays exactly as it was.

A finite aperture is what makes a read mean anything

An aperture is finite, and that is what makes a read mean something: it fixes the question to a bounded region. A read over an unbounded field answers a much broader question — is everything, taken together, ordered? — and on a field that is mostly empty the answer is no.

  • Width dilutes. The same band read +14.33 at 2,048 columns and +0.445 at 32,768. Nothing about it changed.
  • Fix the aperture and move it. Each read stays bounded however large the field grows, and a cheap gate decides where the expensive read runs.
  • Asking many times changes what nothing looks like. A level for one question fires on about one patch in twenty of an empty field, and the sweep raises its own level to match the number of patches it asks about.
  • Report at the resolution you have. The answer is a patch, not a column.

Which is nine reads of the instrument on its own terms: how to organise a record, what to read off it, whether it is ordered at all, what it does along its axis, what to do when it has no numbers, when two of them meet, what “nothing” means, what to do with a third axis, and now what to do when it is simply too big. Unit A10 closes the track with the question underneath all of them — how much record any of these reads needs before its answer means anything.
