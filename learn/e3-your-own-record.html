Your Own Record

Everything so far has been taught on two records. This unit takes a third that nothing in this course has read, and runs the whole procedure on it in order — so what you are watching is the method working, on material chosen for being unfamiliar.

Step one: read it, and ask whether anything is there

Place the grid on a screen and read it. No settings, no fitting, no choice of how many modes to keep:

readvaluewhat it says
Ksignal13modes standing above the floor
contrast32.9328how far the record sits from its own noise
attenuation0.801221how fast influence falls off across the grid
coherence z+43.3901order along the axis running down the page

Every one of those is a large number, and a large number is where a reader should slow down. So ask the question unit A4 exists for: is that order in the land, or does the instrument produce it on anything?

Shuffle the rows into a random order. Every elevation survives; only the arrangement is destroyed. At 5 seeds:

on the land +43.3901  ·  on a shuffle -0.8112 to +0.9120

The order is the record's. A null is the first thing to run. Every number on the table above would have looked just as convincing on a record with nothing in it, and one shuffle settled which of the two this is.

Step two: is there enough record to say it?

Take the top 43 rows, then 86, then 172, then all 344. Same instrument, same width, only the amount changing:

The verdict holds at every length. Even on 43 rows — an eighth of the grid — the coherence reads +12.818, far above the line. A reader who takes away "this land is strongly ordered" is taking away something that held on all four reads.

The mode count does not. Ksignal runs 4, 8, 10, 13 as the rows grow. Thirteen modes is what 344 rows of this grid resolve; 43 rows resolve 4. Unit A11's first test, on a record it was not derived from.

And attenuation turns around: 0.250111, 0.493142, 1.052502, 0.801221. It climbs, then comes back down. A number that reverses under a variation you expected to run one way is a number to carry with the read that produced it, and this deck prints it at each length so a reader can see the turn.

Step three: does the null remove what you are looking for?

Step one used a row shuffle and the coherence collapsed, so the null did its job there. Now run the column reads against that same null, on the same 5 shuffles:

readon the landon a row shuffle
coherence z+43.3901-0.8112 to +0.9120 destroyed
Ksignal1313 at every seeduntouched
contrast32.93284232.932842 at every seeduntouched

The widest any shuffle departs from the record's contrast is 3e-14 — the last bit of a double, from adding the same numbers in a different order.

This is exactly what unit A11 measured on the EEG, and it lands the same way here for the same reason: reordering the rows changes no column's relationship to any other. So the shuffle is a null for the read that looks down the page, and it takes nothing away from the reads that look across it.

Which is the step people skip. The null was correct for the first read, it was already written, and reusing it for the second one would have compared this land against itself and called the result a finding.

Step four: which direction are you asking about?

Every read so far has looked down the page — along the axis the file happens to store first. On the EEG that axis is time and the columns are sensors, so the shape carries a meaning somebody chose. On a piece of land, both directions are directions.

So read the same elevations the other way, and nothing about the land has changed:

down the pageshapeKsignal contrastattenuationz
north–south, as stored344 × 40313 32.93280.801221+43.390
east–west, transposed403 × 34411 43.33671.174318+59.976

Both say strongly ordered, and they say it with different numbers. The verdict is the same in both directions and every magnitude moved: 13 modes against 11, z of +43.390 against +59.976.

Neither reading is the correct one. They are answers to two questions — how does elevation vary as you walk north, and as you walk east — and a fault line is exactly the kind of thing that would make those differ. Unit D8 reads one file at several shapes and finds the same lesson from the other end: the shape is a choice, made by whoever loaded the record.

The practical rule: report which direction you read, alongside the number. A mode count with no direction attached is an answer with the question thrown away.

The order of operations

stepwhat you runwhat it settled here
oneread it, then read a nullthe order is the land's: +43.390 against -0.811 to +0.912
twohalve the recordthe verdict held at every length; Ksignal ran 4, 8, 10, 13
threecheck the null against each readcontrast 32.932842 both times — that null is no null for the column reads
fourread it the other way13 modes north–south, 11 east–west, on the same elevations
  • Run the null first, not last. Every number on step one's table was large and would have looked as convincing on a record with nothing in it. One shuffle settled it in a second.
  • The verdict is what you carry. "Strongly ordered" held on an eighth of the grid and on all of it. "13 modes" held on neither of the other three lengths.
  • One null per read. A row shuffle removes the thing the down-page read measures and leaves the across-page reads numerically identical, to 3e-14.
  • Say which direction. Both readings are correct and they are answers to different questions.

What this unit establishes is what the instrument returns on this grid, and which of those returns survive the four checks. Whether 13 modes tells a geologist anything about a fault is a geologist's question, and it sits outside every measurement on these slides. Reading a record and understanding the ground are two different jobs, and the first one is the only one done here.
